# Portfolio site

Personal portfolio for Sivappriya Arasu. A single page built with plain HTML, CSS and JavaScript:
no build step and no dependencies. The only external request is the Poppins font from Google Fonts.

- Live: https://priya210596.github.io
- Preview locally: open `index.html` in a browser.
- Update: edit the files and push to `main`; GitHub Pages republishes automatically.

The project screenshots come from a fictional demo app. Contact details are assembled in the browser
(`js/main.js`) rather than written in the page source.
